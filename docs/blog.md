# Keep4Life 사용자 가이드

## Keep4Life란?

Keep4Life는 **일상을 기록하고 친구와 공유하는 서비스**입니다.

운동 체크, 체중 기록, 일기, 가계부, 할 일 관리까지 하나의 서비스에서 관리할 수 있습니다. 기록을 공개하면 다른 사용자와 좋아요, 댓글, 채팅으로 소통할 수도 있습니다.

> 서비스 주소: https://keep4.life

> [스크린샷: 홈 화면 전체 모습]

---

## 1. 시작하기

### 1-1. 회원가입

홈 화면에서 **회원가입** 버튼을 눌러 계정을 만듭니다.

> [스크린샷: 회원가입 화면]

입력 항목:
- **이메일**: 로그인할 때 사용하는 주소입니다. 다른 사용자와 중복될 수 없습니다.
- **사용자명**: 본인 이름을 입력합니다.
- **닉네임**: 다른 사용자에게 보이는 이름입니다. 친구 목록, 채팅, 검색 결과 등에서 이 이름이 표시됩니다.
- **비밀번호**: 로그인 비밀번호를 설정합니다.
- **생년월일**: 년, 월, 일을 각각 입력합니다. 히트맵(100년 보기) 기능에서 생년을 기준으로 기록 현황을 표시하는 데 사용됩니다.

가입이 완료되면 "회원가입이 완료되었습니다" 메시지가 표시되고, 잠시 후 로그인 화면으로 이동합니다.

### 1-2. 로그인

가입한 이메일과 비밀번호로 로그인합니다.

> [스크린샷: 로그인 화면]

비밀번호를 잊었다면 로그인 화면에서 **비밀번호 재설정** 링크를 누른 후, 사용자명과 이메일을 입력하여 본인 확인을 하고 새 비밀번호를 설정할 수 있습니다.

> [스크린샷: 비밀번호 재설정 화면]

### 1-3. 프로필 설정

로그인 후 **내 관리** 페이지에서 "프로필 수정" 버튼을 눌러 프로필을 꾸밀 수 있습니다.

> [스크린샷: 프로필 수정 팝업]

수정 가능한 항목:
- **프로필 사진**: 사진을 업로드하면 친구 목록, 채팅, 검색 결과 등 서비스 곳곳에 표시됩니다. 설정하지 않으면 닉네임의 첫 글자가 원형 아이콘 안에 대신 표시됩니다.
- **타이틀**: 페이지 상단에 인사말로 표시되는 한 줄 문구입니다. 설정하지 않으면 기본값 "Hi."가 표시됩니다. (예: "오늘도 화이팅!", "매일 성장하는 중")
- **소개글**: 자기소개를 작성합니다. 타이틀 아래에 표시됩니다. 설정하지 않으면 오늘 날짜가 표시됩니다.
- **닉네임**: 언제든 변경할 수 있습니다.

수정 후 **저장** 버튼을 누르면 변경 사항이 반영됩니다.

## 2. 카테고리

Keep4Life에서는 기록하고 싶은 주제마다 **카테고리**를 만들어 관리합니다.

예를 들어 "매일 운동", "독서 일지", "이번 달 가계부"처럼 자유롭게 만들 수 있습니다. 카테고리마다 하나의 기록 방식을 선택하고, 그 안에 날짜별 기록을 쌓아갑니다.

### 2-1. 카테고리 만들기

**카테고리** 페이지에서 새 카테고리를 만듭니다. 상단의 입력 폼에 다음 항목을 채웁니다.

> [스크린샷: 카테고리 추가 폼]

1. **제목** (필수): 카테고리 이름을 입력합니다. (예: "매일 운동")
2. **설명** (선택): 카테고리에 대한 간단한 설명을 적습니다. (예: "하루 30분 이상 운동 기록")
3. **타입** (필수): 기록 방식을 선택합니다. 드롭다운 메뉴에서 아래 6가지 중 하나를 고릅니다.
   - CHECK - 성공/실패 기록
   - TEXT - 텍스트 기록
   - TIME - 시간 기록
   - NUMBER - 숫자 기록
   - CHECKLIST - 할일 목록
   - EXPENSE - 가계부 기록
4. **공개 설정** (필수): 카테고리의 공개 범위를 정합니다.
   - **PRIVATE - 나만 보기**: 본인만 볼 수 있습니다.
   - **PUBLIC - 공개**: 다른 사용자들이 홈 화면에서 이 카테고리를 열람하고, 좋아요와 댓글을 남길 수 있습니다.

모든 항목을 채운 후 **카테고리 추가** 버튼을 누르면 생성됩니다.

> 한 번 선택한 타입(기록 방식)은 나중에 변경할 수 없습니다. 카테고리를 만들 때 신중하게 선택해주세요.

### 2-2. 카테고리 관리

만든 카테고리는 카테고리 페이지 하단에 카드 형태의 목록으로 표시됩니다. 각 카드에는 제목, 설명, 타입 뱃지, 좋아요 수, 댓글 수가 함께 표시됩니다.

> [스크린샷: 카테고리 카드 목록]

**수정하기**: 카테고리 카드를 클릭하면 수정 팝업이 열립니다. 제목, 설명, 공개 설정을 변경할 수 있습니다. (타입은 변경 불가) 수정 후 **저장** 버튼을 누릅니다.

> [스크린샷: 카테고리 수정 팝업]

**삭제하기**: 수정 팝업에서 **삭제** 버튼을 누르면 카테고리와 그 안의 모든 기록이 함께 삭제됩니다.

**좋아요 확인**: 카드의 좋아요 버튼을 누르면 해당 카테고리에 좋아요를 누른 사용자 목록을 팝업으로 확인할 수 있습니다. 각 사용자의 프로필 사진(또는 이니셜)과 이메일이 표시됩니다.

## 3. 기록하기

카테고리를 만든 후 **내 관리** 페이지에서 실제 기록을 추가합니다.

### 3-0. 내 관리 페이지 구조

내 관리 페이지에 들어가면, 화면 왼쪽 가장자리에 **서랍 패널**이 있습니다. 서랍은 PUBLIC(공개)과 PRIVATE(비공개) 두 개로 나뉘어 있고, 각각 해당 공개 설정의 카테고리 목록을 보여줍니다. 서랍의 손잡이에는 카테고리 개수가 뱃지로 표시됩니다.

> [스크린샷: 내 관리 페이지 - 서랍 패널이 펼쳐진 모습]

마우스를 서랍 위에 올리면 패널이 펼쳐지고, 원하는 카테고리를 클릭하면 화면 중앙에 해당 카테고리의 기록이 표시됩니다. 상단에는 보기 방식 전환 버튼과 **기록 추가** 버튼이 나타납니다.

### 3-1. CHECK (체크)

**"했다 / 안했다"를 기록합니다.**

매일 성공 여부만 체크하는 가장 간단한 방식입니다. 습관을 만들고 싶을 때 사용합니다.

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **날짜**를 선택합니다.
3. **성공 여부** 체크박스를 체크하거나 해제합니다.
4. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: CHECK 기록 추가 팝업]

**활용 예시:**
- 운동 했는지 안 했는지
- 아침 기상 성공 여부
- 금연/금주 체크
- 물 8잔 마시기
- 비타민 복용 여부

달력 형태의 테이블에서 한 달 동안 며칠을 성공했는지 한눈에 확인할 수 있습니다. 성공한 날은 초록색, 실패한 날은 빨간색으로 표시되어 연속 달성 기록이 직관적으로 보입니다.

> [스크린샷: CHECK 테이블 뷰 - 초록/빨간 셀이 보이는 달력]

### 3-2. TEXT (텍스트)

**글과 사진을 함께 기록합니다.**

일기처럼 자유롭게 글을 쓰고, 사진을 여러 장 첨부할 수 있습니다.

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **날짜**를 선택합니다.
3. **제목**을 입력합니다. (예: "오늘의 생각")
4. **내용**을 자유롭게 작성합니다. 여러 줄 입력이 가능합니다.
5. **이미지 추가** 버튼을 눌러 사진을 첨부합니다. 한 번에 여러 장을 선택할 수 있습니다.
6. 선택한 파일 이름이 표시되고, 아래에 미리보기가 나타납니다.
7. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: TEXT 기록 추가 팝업 - 이미지 미리보기 포함]

**이미지 기능:**
- 여러 장의 사진을 업로드하면 캐러셀(슬라이드) 형태로 좌우 화살표를 눌러 넘겨볼 수 있습니다.
- 기록을 수정할 때 개별 이미지를 선택하여 삭제할 수 있습니다.
- 이미지가 없는 텍스트 기록도 가능합니다.

> [스크린샷: TEXT 리스트 뷰 - 이미지 캐러셀이 보이는 기록]

**활용 예시:**
- 일기
- 독서 감상문
- 요리 레시피 (완성 사진과 함께)
- 여행 기록 (여행지 사진과 함께)
- 프로젝트 진행 메모

### 3-3. TIME (시간)

**시각이나 소요 시간을 기록합니다.**

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **날짜**를 선택합니다.
3. **시간**을 입력합니다. (시:분 형식)
4. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: TIME 기록 추가 팝업]

**활용 예시:**
- 매일 기상 시간
- 취침 시간
- 운동 시작 시간
- 공부 소요 시간
- 출근 시간

매일 기록하면 생활 패턴이 어떻게 변하고 있는지 테이블이나 캘린더에서 한눈에 파악할 수 있습니다.

### 3-4. NUMBER (숫자)

**수치 데이터를 기록합니다.**

소수점도 입력할 수 있어서 정밀한 수치 기록이 가능합니다.

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **날짜**를 선택합니다.
3. **숫자**를 입력합니다. (예: 72.5)
4. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: NUMBER 기록 추가 팝업]

**활용 예시:**
- 체중 (예: 72.5kg)
- 걸음 수 (예: 8432)
- 독서 페이지 수 (예: 35)
- 혈압 (예: 120)
- 수면 시간 (예: 7.5)

이 타입의 가장 큰 장점은 **꺾은선 그래프**로 변화 추이를 볼 수 있다는 것입니다. 시간이 지남에 따라 체중이 줄고 있는지, 걸음 수가 늘고 있는지 한눈에 확인됩니다.

> [스크린샷: NUMBER 그래프 뷰 - 꺾은선 차트]

### 3-5. CHECKLIST (체크리스트)

**할 일 목록을 날짜별로 관리합니다.**

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **날짜**를 선택합니다.
3. **할 일** 내용을 입력합니다. (예: "운동하기")
4. **완료 여부** 체크박스를 설정합니다.
5. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: CHECKLIST 기록 추가 팝업]

**CHECK 타입과의 차이점:**
- CHECK: 카테고리 전체가 하나의 성공/실패 → "운동을 했다/안했다"
- CHECKLIST: 여러 개의 할 일 항목을 등록 가능 → "스쿼트 30개", "플랭크 1분", "스트레칭"

같은 날짜에 여러 항목을 등록할 수 있어서, 세부적인 할 일 관리에 적합합니다.

> [스크린샷: CHECKLIST 리스트 뷰 - 여러 항목이 보이는 기록]

**활용 예시:**
- 일일 TODO 리스트
- 아침 루틴 (세수, 운동, 아침식사, 비타민)
- 학습 계획 (수학 1장, 영어 단어 50개)
- 청소 체크리스트

### 3-6. EXPENSE (가계부)

**수입과 지출을 상세하게 기록합니다.**

6가지 기록 방식 중 가장 다양한 입력 항목을 제공합니다.

**기록 추가:**
1. 기록 추가 버튼을 누릅니다.
2. **수입/지출 구분**: 상단의 버튼으로 선택합니다. 토글 형태로 하나만 선택됩니다.
3. **금액**: 얼마인지 입력합니다. (원화 기호가 자동으로 붙습니다)
4. **날짜**: 언제 사용했는지 선택합니다.
5. **결제수단**: 아래 4가지 중 하나를 눌러 선택합니다.
   - 카드
   - 현금
   - 이체
   - 기타
6. **가맹점**: 어디서 사용했는지 적습니다. (예: "스타벅스", "쿠팡", "넷플릭스")
7. **메모**: 추가 설명을 적습니다. (예: "친구 생일 선물")
8. **태그**: 분류 태그를 붙입니다.
9. **추가** 버튼을 누르면 저장됩니다.

> [스크린샷: EXPENSE 기록 추가 팝업 - 전체 입력 폼]

**태그 기능:**

태그는 지출/수입을 분류하는 라벨입니다. 나만의 분류 체계를 만들 수 있습니다.

- 기존에 만든 태그 목록이 표시되며, 클릭하여 선택/해제할 수 있습니다.
- 새 태그를 만들려면 입력창에 태그 이름을 적고 **태그** 버튼을 누릅니다.
- 하나의 기록에 여러 태그를 동시에 붙일 수 있습니다. (예: "카페" + "친구 만남")
- 선택된 태그는 칩(chip) 형태로 표시되고, X 버튼으로 제거할 수 있습니다.
- 태그 예시: "식비", "교통비", "문화생활", "쇼핑", "의료비", "월급", "용돈"

> [스크린샷: 태그 선택/생성 영역]

**자동 요약:**

가계부 기록이 쌓이면 자동으로 계산되는 요약 정보가 표시됩니다.
- 총 수입
- 총 지출
- 잔액 (수입 - 지출)

> [스크린샷: 가계부 요약 (총 수입/지출/잔액)]

### 3-7. 기록 수정 & 삭제

모든 기록 타입에서 수정과 삭제가 가능합니다.

**수정**: 기록 옆의 수정 버튼(연필 아이콘)을 누르면 수정 팝업이 열립니다. 기존 값이 채워진 상태에서 원하는 항목을 변경하고 저장합니다. 텍스트 타입의 경우 이미지를 추가하거나 기존 이미지를 개별 삭제할 수 있습니다.

**삭제**: 기록 옆의 삭제 버튼(휴지통 아이콘)을 누르면 "정말 삭제하시겠습니까?" 확인 메시지가 나타납니다. 확인을 누르면 해당 기록이 삭제됩니다.

> [스크린샷: 기록 수정/삭제 버튼이 보이는 기록 항목]

## 4. 기록 확인하기 - 보기 방식

기록한 데이터를 여러 가지 방식으로 확인할 수 있습니다. 카테고리를 선택하면 상단에 보기 방식 전환 버튼이 나타나며, 클릭 한 번으로 전환됩니다. 기록 타입에 따라 사용 가능한 보기 방식이 다릅니다.

> [스크린샷: 보기 방식 전환 버튼 영역]

### 4-1. 그래프

숫자(NUMBER)와 가계부(EXPENSE) 타입에서 사용할 수 있습니다.

시간 흐름에 따른 수치 변화를 **꺾은선 차트**로 보여줍니다. 가로축은 날짜, 세로축은 값입니다.

- 체중이 줄고 있는지, 지출이 늘고 있는지 추세를 직관적으로 파악할 수 있습니다.
- 가계부의 경우 수입과 지출을 함께 비교할 수 있습니다.

> [스크린샷: 그래프 뷰 - 꺾은선 차트]

### 4-2. 테이블

CHECK, TEXT, TIME, NUMBER 타입에서 사용할 수 있습니다.

날짜별 기록을 **달력 형태의 표**로 보여줍니다. 한 달 동안의 기록을 한눈에 파악하기 좋습니다.

- CHECK 타입: 성공은 초록색, 실패는 빨간색 셀로 표시
- NUMBER 타입: 각 셀에 숫자 값이 표시
- 각 기록에 수정/삭제 버튼이 함께 표시됩니다.

> [스크린샷: 테이블 뷰 - 달력 형태의 기록 표]

### 4-3. 캘린더

모든 타입에서 사용할 수 있습니다.

월별 달력에 기록이 있는 날이 색상으로 표시됩니다. 기록이 있는 날은 파란색(또는 타입별 색상), 없는 날은 회색으로 표시되어 어떤 날에 빠뜨렸는지 쉽게 알 수 있습니다.

셀을 클릭하면 해당 날짜의 기록 상세 내용을 확인하거나 새 기록을 추가할 수 있습니다.

> [스크린샷: 캘린더 뷰 - 색상이 표시된 월별 달력]

### 4-4. 리스트

TEXT, CHECKLIST, EXPENSE 타입에서 사용할 수 있습니다.

기록을 카드 형태로 위에서 아래로 나열합니다. 최신 기록이 위에 표시됩니다.

- 텍스트: 제목, 내용, 이미지 미리보기
- 체크리스트: 할 일 항목과 완료 상태
- 가계부: 금액, 결제수단, 가맹점, 태그

각 항목에 수정/삭제 버튼이 함께 표시되어 바로 편집할 수 있습니다.

> [스크린샷: 리스트 뷰 - 카드 형태로 나열된 기록]

### 4-5. 히트맵 (100년 보기)

모든 타입에서 사용할 수 있습니다.

회원가입 시 입력한 **생년을 기준으로 100년간**의 기록 현황을 한 화면에 보여주는 독특한 뷰입니다.

- 가로축: 월(1~12월)
- 세로축: 연도(생년 ~ 생년+100)
- 각 칸이 하루를 나타내며, 기록 여부에 따라 색상 농도가 달라집니다.

**색상 의미:**
- CHECK 타입: 성공(초록), 실패(빨간), 기록 없음(연한 회색)
- 기타 타입: 기록 있음(파란), 기록 없음(연한 회색), 미래 날짜(흰색)

인생 전체에서 내가 얼마나 꾸준히 기록해왔는지를 한 장의 그림으로 보여줍니다. 빈 칸이 보이면 동기부여가 되기도 합니다.

각 셀을 클릭하면 해당 날짜의 기록을 수정할 수 있습니다.

> [스크린샷: 히트맵 뷰 - 100년 전체가 보이는 화면]

### 4-6. 주간 뷰 (가계부 전용)

가계부(EXPENSE) 타입에서만 사용할 수 있습니다.

월~일 7일간의 지출/수입을 요약합니다.

- 각 요일별 금액이 표시됩니다.
- 주 단위 총합이 함께 표시됩니다.
- 이전 주 / 다음 주 버튼으로 주간 이동이 가능합니다.

> [스크린샷: 주간 뷰 - 요일별 금액 요약]

### 4-7. 월간 뷰 (가계부 전용)

가계부(EXPENSE) 타입에서만 사용할 수 있습니다.

한 달 전체 달력에 일별 지출 금액이 표시됩니다.

- 금액이 큰 날일수록 색이 진하게 표시됩니다.
- 월 전체 총합이 상단에 표시됩니다.
- 이전 월 / 다음 월 버튼으로 월간 이동이 가능합니다.

> [스크린샷: 월간 뷰 - 달력에 금액이 표시된 모습]

## 5. 다른 사용자와 소통하기

### 5-1. 공개 카테고리 둘러보기

**홈** 화면에서 다른 사용자들이 공개 설정한 카테고리를 둘러볼 수 있습니다.

카테고리 카드에는 다음 정보가 표시됩니다:
- 카테고리 이미지 또는 제목 첫 글자
- 제목과 설명
- 기록 타입 뱃지 (CHECK, TEXT 등)
- 만든 사람의 닉네임과 이메일
- 좋아요 수와 댓글 수

> [스크린샷: 홈 화면 - 공개 카테고리 카드 목록]

**검색**: 상단 검색창에 키워드를 입력하면 카테고리를 검색할 수 있습니다.

**정렬**: 드롭다운 메뉴에서 정렬 기준을 선택할 수 있습니다.
- 좋아요 수 순
- 댓글 수 순
- 최근 업데이트 순
- 오름차순 / 내림차순 전환

로그인하지 않아도 공개 카테고리 목록은 볼 수 있지만, 좋아요와 댓글은 로그인 후에만 가능합니다.

### 5-2. 좋아요

마음에 드는 카테고리에 좋아요를 누를 수 있습니다.

- 좋아요 버튼을 누르면 좋아요가 추가되고, 다시 누르면 취소됩니다.
- 좋아요를 누르면 버튼 색상이 파란색으로 변하며, 옆에 숫자가 업데이트됩니다.
- 카테고리 만든 사람에게 "좋아요" 알림이 전송됩니다.
- 좋아요 버튼을 다시 클릭하면 누가 좋아요를 눌렀는지 사용자 목록을 팝업으로 확인할 수 있습니다. 각 사용자의 프로필 사진(또는 이니셜)과 이메일이 표시됩니다.

> [스크린샷: 좋아요 버튼 + 좋아요 사용자 목록 팝업]

### 5-3. 댓글 & 답글

공개 카테고리에 댓글을 남기고 대화를 이어갈 수 있습니다.

**댓글 달기:**
1. 카테고리 카드의 **댓글** 버튼을 누르면 댓글 팝업이 열립니다.
2. 팝업 상단에 카테고리 이름이 표시됩니다.
3. 기존 댓글들이 목록으로 보입니다. 각 댓글에는 작성자 이메일, 작성 시간이 표시됩니다.
4. 내가 쓴 댓글에는 **"ME"** 뱃지가 붙고, 수정된 댓글에는 **(수정됨)** 표시가 나타납니다.
5. 하단 입력창에 댓글을 작성하고 **댓글** 버튼을 누르면 등록됩니다.

> [스크린샷: 댓글 팝업 - 댓글 목록과 입력창]

**답글 달기:**
- 다른 사람의 댓글 옆 **답글** 버튼을 누르면, 해당 댓글 아래에 답글 입력창이 나타납니다.
- 답글은 원래 댓글 아래에 들여쓰기되어 표시되므로 대화 맥락이 유지됩니다.

> [스크린샷: 답글이 들여쓰기된 댓글 구조]

**댓글 수정:**
- 내가 쓴 댓글의 **수정** 버튼을 누르면 댓글 내용을 수정할 수 있는 입력창이 나타납니다.
- 수정 후 저장하면 "(수정됨)" 표시가 붙습니다.

**댓글 삭제:**
- 내가 쓴 댓글의 **삭제** 버튼을 누르면 확인 메시지가 나타나고, 확인을 누르면 삭제됩니다.

카테고리 주인에게는 댓글이 달릴 때, 댓글 작성자에게는 답글이 달릴 때 실시간 알림이 전송됩니다.

### 5-4. 친구 추가하기

**소셜** 페이지에서 다른 사용자를 찾고 친구를 맺을 수 있습니다.

> [스크린샷: 소셜 페이지 전체 화면]

**친구 요청 보내기:**
1. 소셜 페이지 우측의 **사용자 검색** 영역에서, 검색창에 닉네임 또는 이메일을 입력합니다.
2. **검색** 버튼을 누르면 검색 결과가 아래에 표시됩니다.
3. 각 사용자에게 프로필 사진(또는 이니셜), 닉네임, 이메일이 표시됩니다.
4. 사용자 옆의 **친구 요청** 버튼을 누르면 요청이 전송됩니다.
5. "친구 요청을 보냈습니다" 알림이 나타나고, 상대방에게 실시간 알림이 갑니다.

> [스크린샷: 사용자 검색 결과 - 친구 요청 버튼, 요청됨, 친구 상태가 보이는 목록]

**검색 결과의 상태 표시:**

이미 관계가 있는 사용자는 버튼 대신 상태가 표시됩니다.
- 아무 관계 없음 → 파란색 **"친구 요청"** 버튼
- 요청을 보낸 상태 → 회색 **"요청됨"** 텍스트
- 이미 친구인 상태 → 초록색 **"친구"** 텍스트

**받은 요청 처리하기:**

소셜 페이지 우측 하단의 **받은 친구 요청** 영역에서 다른 사용자가 보낸 요청을 확인합니다.
- 요청한 사용자의 프로필 사진, 닉네임, 이메일이 표시됩니다.
- 초록색 **수락** 버튼을 누르면 친구가 됩니다. 상대방에게 "친구 요청을 수락했습니다" 알림이 전송됩니다.
- 회색 **거절** 버튼을 누르면 요청이 거절됩니다.
- 요청이 없으면 "받은 요청이 없습니다"라고 표시됩니다.

> [스크린샷: 받은 친구 요청 영역 - 수락/거절 버튼]

### 5-5. 친구 목록

소셜 페이지 좌측 패널의 **친구** 탭에서 친구 목록을 확인합니다.

각 친구에게 다음 정보가 표시됩니다:
- 프로필 사진 (없으면 닉네임 첫 글자)
- 닉네임
- 이메일
- **채팅** 버튼

친구를 클릭하면 바로 채팅방이 열립니다. 친구가 없으면 "친구가 없습니다"라고 표시됩니다.

> [스크린샷: 친구 목록 - 프로필과 채팅 버튼]

### 5-6. 1:1 채팅

친구와 실시간으로 메시지를 주고받을 수 있습니다.

**채팅 시작하기:**
- 방법 1: 친구 목록에서 친구를 클릭하면, 해당 친구와의 채팅방이 자동으로 생성되고 채팅 화면으로 전환됩니다.
- 방법 2: 좌측 패널의 **채팅** 탭을 눌러 기존 채팅방 목록에서 선택합니다.

**채팅 화면 구성:**

화면이 좌우 두 영역으로 나뉩니다.

| 왼쪽 패널 (320px) | 오른쪽 패널 |
|---|---|
| **친구 탭**: 친구 목록 | **채팅 헤더**: 상대방 프로필 사진, 닉네임, 이메일 |
| **채팅 탭**: 채팅방 목록 | **대화 영역**: 메시지 목록 (스크롤) |
| 탭 전환 버튼 | **입력 영역**: 메시지 입력창 + 전송 버튼 |

> [스크린샷: 채팅 화면 전체 - 좌측 패널 + 우측 대화 영역]

**채팅방 목록에 표시되는 정보:**
- 상대방 프로필 사진 (없으면 닉네임 첫 글자)
- 상대방 닉네임
- 마지막 메시지 미리보기 (대화가 없으면 "새 채팅")
- 마지막 메시지 시간 (방금 전, 3분 전, 2시간 전 등)
- 안 읽은 메시지 수 빨간 뱃지 (있는 경우)

> [스크린샷: 채팅방 목록 - 안 읽은 메시지 뱃지 포함]

**메시지 표시:**
- 내가 보낸 메시지: **오른쪽 정렬**, 파란색 배경, 흰색 글자
- 상대방 메시지: **왼쪽 정렬**, 연한 회색 배경, 검은색 글자
- 각 메시지 아래에 전송 시간이 작게 표시됩니다.
- 날짜가 바뀌면 "2026-01-15" 같은 날짜 구분선이 가운데에 표시됩니다.

> [스크린샷: 대화 영역 - 내 메시지(파란)와 상대 메시지(회색)가 보이는 대화]

**메시지 보내기:**
- 하단 입력창에 메시지를 작성합니다.
- **전송** 버튼을 누르거나 **Enter** 키를 누르면 메시지가 전송됩니다.
- 전송 후 대화 영역이 자동으로 맨 아래로 스크롤됩니다.

**읽음 처리:**
- 채팅방에 들어가면 안 읽은 메시지가 자동으로 읽음 처리됩니다.
- 채팅방 목록의 빨간 뱃지가 사라집니다.
- 채팅 탭의 전체 안 읽은 메시지 수 뱃지도 업데이트됩니다.

## 6. 알림

다른 사용자의 활동이 있을 때 실시간으로 알림을 받습니다. 페이지를 새로고침하지 않아도 자동으로 도착합니다.

### 6-1. 알림을 받는 경우

| 상황 | 알림 예시 |
|------|----------|
| 내 카테고리에 댓글이 달릴 때 | "[운동 기록] user@email.com: 대단하세요!" |
| 내 댓글에 답글이 달릴 때 | "user@email.com님이 답글을 남겼습니다" |
| 내 카테고리에 좋아요를 받을 때 | "user@email.com님이 좋아요를 눌렀습니다" |
| 친구 요청을 받을 때 | "홍길동님이 친구 요청을 보냈습니다" |
| 보낸 요청이 수락될 때 | "홍길동님이 친구 요청을 수락했습니다" |
| 새 채팅 메시지가 올 때 | "홍길동: 안녕하세요!" |

### 6-2. 알림 확인 방법

알림은 세 가지 방식으로 확인할 수 있습니다.

**1. 토스트 팝업**

알림이 도착하면 화면 오른쪽 위에 작은 팝업이 나타납니다. 알림 종류(새 댓글, 친구 요청 등), 내용, 시간이 표시됩니다. 5초 후 자동으로 사라지며, 클릭하면 알림 목록이 열립니다.

> [스크린샷: 토스트 알림 팝업 - 화면 우상단]

**2. 알림 뱃지**

모든 페이지 상단의 **알림** 버튼 옆에 읽지 않은 알림 수가 숫자로 표시됩니다. 99개를 초과하면 "99+"로 표시됩니다. 모든 알림을 읽으면 뱃지가 사라집니다.

> [스크린샷: 상단 네비게이션 바 - 알림 뱃지가 표시된 모습]

**3. 알림 목록 팝업**

상단의 **알림** 버튼을 클릭하면 전체 알림 목록이 팝업으로 열립니다.

- 각 알림에는 **유형 라벨**(댓글, 답글, 좋아요, 친구 요청, 친구 수락, 메시지), 보낸 사람, 내용, 상대 시간(방금 전, 5분 전, 2시간 전, 1일 전)이 표시됩니다.
- 읽지 않은 알림은 배경색이 다르게 표시됩니다.
- 알림을 **클릭하면 읽음 처리**됩니다.
- 상단의 **모두 읽음** 버튼을 누르면 모든 알림이 한 번에 읽음 처리됩니다.
- 알림이 하나도 없으면 "알림이 없습니다"가 표시되고, **모두 읽음** 버튼은 비활성화됩니다.
- 팝업 바깥 영역을 클릭하거나 X 버튼을 누르면 팝업이 닫힙니다.

> [스크린샷: 알림 목록 팝업 - 여러 유형의 알림이 보이는 모습]

## 7. 언어 전환

화면 상단의 **KO / EN** 버튼을 누르면 한국어와 영어를 즉시 전환할 수 있습니다.

> [스크린샷: KO/EN 언어 전환 버튼]

- 현재 한국어면 "EN" 버튼이 표시되고, 누르면 영어로 바뀌면서 "KO" 버튼이 표시됩니다.
- 모든 버튼 라벨, 안내 문구, 입력창 힌트 텍스트, 알림 메시지, 빈 화면 안내 문구 등 화면에 보이는 모든 텍스트가 선택한 언어로 바뀝니다.
- 한 번 선택한 언어는 저장되어, 브라우저를 닫았다가 다시 방문해도 같은 언어가 유지됩니다.
- 페이지가 열릴 때 이전에 선택한 언어가 즉시 적용되므로, 잠깐 다른 언어가 보였다가 바뀌는 깜빡임이 없습니다.

## 8. 페이지 안내

Keep4Life는 4개의 주요 페이지로 구성되어 있습니다.

| 페이지 | 설명 |
|--------|------|
| **홈** | 다른 사용자의 공개 카테고리를 둘러보고, 좋아요와 댓글을 남깁니다. 검색과 정렬 기능으로 원하는 카테고리를 찾을 수 있습니다. |
| **카테고리** | 나의 카테고리를 만들고, 수정하고, 삭제합니다. 기록 방식과 공개 범위를 설정합니다. |
| **내 관리** | 왼쪽 서랍에서 카테고리를 선택하고, 기록을 추가/수정/삭제합니다. 그래프, 테이블, 캘린더, 히트맵 등 다양한 방식으로 기록을 확인합니다. 프로필도 여기서 수정합니다. |
| **소셜** | 사용자를 검색하고 친구를 추가합니다. 받은 친구 요청을 수락/거절합니다. 친구와 1:1 채팅을 합니다. |

> [스크린샷: 상단 네비게이션 바 - 홈, 카테고리, 내 관리, 소셜, 알림, 로그아웃 버튼]

모든 페이지 상단에 **홈, 카테고리, 내 관리, 소셜, 알림, 로그아웃** 버튼이 있어서 어디서든 원하는 페이지로 바로 이동할 수 있습니다.
